# Website build workflow

Read [the bundled playbook](../../../website-builder/README.md). Fill the seven-slot brief from the user's actual audience, business facts, brand, assets, and constraints; identify consequential unknowns before implementation.

Check which specialist design/media skills are available. The playbook references separate tools that are not bundled or automatically installed. Use available capabilities honestly, and explain any dependency that prevents the requested result. Do not invent generated assets, completed builds, or successful tool calls.

Build a working local preview using the chosen project's stack. Preserve the client brand and real content. Follow [the accessibility checklist](../../../website-builder/wcag-aa-checklist.md) and the sibling [ada-audit skill](../ada-audit/SKILL.md). Resolve verified failures and document outstanding manual checks.

Present the working preview and tested behavior. Publish only when the user has authorized publication. Keep credentials, client records, and generated site output out of this shared toolkit repository.
