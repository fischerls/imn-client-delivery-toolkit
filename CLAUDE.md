# Toolkit routing

This repository contains three workflows. Read README.md first and choose the requested workflow.

- SEO: work from `seo-command-center/` and read its CLAUDE.md. Its skills, SOPs, templates, and local configuration use that directory as their root. If local config or dashboard files are absent, copy their `.example.md` counterparts before setup; do not edit the tracked examples for a particular agency.
- Website building: read `website-builder/README.md`. Identify available specialist dependencies first. Respect the user's actual brand and constraints. Produce a reviewable preview before publishing unless publishing is already authorized.
- Accessibility: use `.claude/skills/ada-audit/SKILL.md`. Preserve full evidence and explicit manual/unknown states. Automated results are not a legal ADA determination.

Save generated work in ignored client, prospect, or audit folders. Never commit credentials, authentication state, real client records, or audit evidence. Do not send messages or make production changes unless the user authorized those actions.
